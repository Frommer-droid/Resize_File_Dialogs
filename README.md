# Resize_File_Dialogs

**Windows-приложение для автоматического изменения размера и позиции выбранных окон.**

Resize_File_Dialogs хранит правила окон, генерирует AutoHotkey-скрипт и
запускает его из GUI. Приложение удобно для диалогов выбора файлов, служебных
окон и других окон, которые нужно каждый раз открывать в предсказуемом размере
и месте экрана.

Текущая версия: **1.5.0**.

## Возможности

- правила по классу окна, части заголовка, размеру и позиции;
- временное отключение правила и отдельных заголовков чекбоксами;
- список исключений по заголовкам окон;
- встроенный Spy для определения класса и заголовка окна через `pywin32`;
- генерация и запуск `generated_resizer.ahk`;
- импорт и экспорт правил и исключений в JSON;
- работа через системный трей;
- переключатель «Пауза / Возобновить» в меню трея для приостановки регулировки окон;
- автозапуск при входе в Windows через планировщик задач с повышенными правами;
- запуск свернутым в трей;
- адаптивное масштабирование интерфейса от размера экрана и DPI;
- ручная поправка масштаба интерфейса в диапазоне от `-50%` до `+50%`;
- регулируемые разделители между колонками интерфейса;
- единая версия через `VERSION` и `app/version.py`;
- автономная сборка с портативным `AutoHotkey.exe`.

## Быстрый старт

### Готовая сборка

1. Запустите `Resize_File_Dialogs.exe` от имени администратора.
2. На вкладке правил нажмите `Добавить`.
3. Укажите имя правила, класс окна, фрагменты заголовков, ширину, высоту и
   позицию.
4. При необходимости включите Spy и кликните по нужному окну, чтобы заполнить
   класс и заголовок.
5. Нажмите `Сохранить`.
6. Нажмите `Старт`, чтобы запустить AutoHotkey-скрипт.

После запуска скрипт проверяет открытые окна и применяет первое подходящее
правило. Если окно попадает в список исключений, оно не изменяется.

### Запуск из исходников

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\pythonw.exe .\Resize_File_Dialogs.pyw
```

Если `.venv` уже существует, запуск через другой Python из папки проекта
автоматически перезапустится через `.venv\Scripts\pythonw.exe`, чтобы GUI не
открывал лишнее консольное окно.

## Как работает приложение

Приложение хранит правила в `settings.json`, на их основе создает
`generated_resizer.ahk` и запускает его через AutoHotkey v2. Скрипт раз в
секунду просматривает открытые окна, сравнивает класс и заголовок с правилами и
вызывает `WinMove`, если окно нужно переставить или изменить.

Правило содержит:

- имя правила;
- класс окна;
- один или несколько фрагментов заголовка;
- целевую ширину и высоту;
- позицию: слева, по центру, справа, углы или верх/низ экрана.

Приложение сохраняет изменения правил сразу после редактирования, а также при
завершении Windows-сессии. Чистый первый запуск начинается с пустого списка
правил и исключений.

## Интерфейс

Слева расположены вкладки «Правила», «Исключения» и «Система»; справа — кнопки
«Старт/Стоп», управление правилами, инспектор окон и лог событий. Во вкладке
«Правила» список правил и форма настройки разделены перетаскиваемым
разделителем. Отключить правило или отдельный заголовок можно чекбоксом — они
пропускаются при генерации скрипта до повторного включения.

## Настройки

| Файл                                            | Назначение                                             |
| ----------------------------------------------- | ------------------------------------------------------ |
| `settings.json`                                 | правила, исключения, состояние окна, трей и масштаб UI |
| `generated_resizer.ahk`                         | сгенерированный AutoHotkey-скрипт                      |
| `VERSION`                                       | единый источник версии                                 |
| `logo.ico`                                      | иконка приложения                                      |
| `AutoHotKey\AutoHotkey.exe`                     | портативный AutoHotkey в исходниках                    |
| `Resize_File_Dialogs\AutoHotkey\AutoHotkey.exe` | AutoHotkey в собранной папке                           |

`settings.json`, логи и собранная папка не коммитятся. `generated_resizer.ahk`
отслеживается как стартовый скрипт и может перегенерироваться локально при
работе приложения; пользовательские правила не включаются в релиз без отдельного
решения. Для старых установок поддерживается fallback на
`ahk_resizer_generator_settings.json`.

## Автозапуск и трей

На вкладке `Система` доступны две независимые настройки:

- `Автозапуск при входе в Windows`;
- `Запускать свернутым в трей`.

Автозапуск создается через задачу планировщика Windows
`Resize_File_Dialogs` с `RunLevel=HighestAvailable` и задержкой 15 секунд после
входа пользователя. Если `schtasks.exe` недоступен, приложение использует
fallback-ярлык в системно определенной пользовательской папке Startup. Если
Startup перенесен, например на `D:\Startup`, ярлык создается именно там, а не в
дефолтном `%APPDATA%`-пути.

Закрытие окна крестиком скрывает приложение в трей. Полный выход выполняется
через пункт `Выход` в меню иконки трея.

## Масштаб интерфейса

Версия 1.3.0 добавила автоматический расчет масштаба от доступного размера
экрана и DPI. Ручная поправка сохраняется в `settings.json` через
`ui_scale_delta_percent`, а итоговый диагностический процент хранится как
`ui_scale_percent`.

Автомасштаб проверяется unit-тестами в `tests\test_ui_scale.py`, а выбор
системного Startup-пути — в `tests\test_autostart_paths.py`.

## Сборка и релиз

Сборка onedir-папки PyInstaller:

```powershell
.\.venv\Scripts\pythonw.exe .\Build_Tools\SpecCompiler.pyw
```

В окне сборщика выберите:

```text
Build_Tools\Resize_File_Dialogs.spec
```

После успешной сборки `Build_Tools\post_build.py` переносит результат в корень
проекта как `Resize_File_Dialogs\`, копирует `VERSION`, `logo.ico`,
портативный AutoHotkey и корневые JSON-файлы.

Дополнительные релизные скрипты:

| Скрипт               | Что делает                                                      |
| -------------------- | --------------------------------------------------------------- |
| `00_Move.pyw`        | копирует готовую папку в `D:\Portable_soft\Resize_File_Dialogs` |
| `00_CrRel-setup.pyw` | создает installer `Resize_File_Dialogs_vX.Y.Z_Setup.exe`        |

Installer staging очищается от runtime-файлов: `.env`, `settings.json`,
`ahk_resizer_generator_settings.json`, `generated_resizer.ahk` и логов.

## Ограничения

- приложение работает только под Windows;
- для полноценной работы нужны права администратора;
- Spy-функции зависят от `pywin32`;
- приложение не управляет окнами напрямую в фоновом Python-процессе, а
  делегирует ресайз AutoHotkey-скрипту;
- правила применяются по классу окна и фрагментам заголовков, поэтому слишком
  общие заголовки могут затронуть лишние окна.
