# История изменений (Release Notes)

## Версия 1.6.0 (2026-09-24)

*Интерфейс приведён к палитре One Dark; сборка теперь проверяет происхождение DLL и запускает отдельную frozen-фикстуру.*

### ✨ Новые возможности

- Основное окно и сборщик используют единую палитру One Dark с состояниями кнопок и элементов управления.
- Добавлены английский README и сведения о лицензиях собственного кода и стороннего AutoHotkey.

### 🐛 Исправления ошибок

- Собранный пакет получает согласованный комплект MSVC runtime из PySide6 вместо смешения версий Python и Qt.
- В installer-скрипте путь вывода определяется по системному расположению рабочего стола.
- Заголовок окна показывает актуальное название Resize_File_Dialogs.
- Windows-метаданные EXE теперь содержат версию из `VERSION`.
- Обновление portable-папки сохраняет её текущие настройки и сгенерированный AHK-скрипт, даже если в новой сборке уже есть `settings.json`.

### 🛠 Улучшения

- PyInstaller отклоняет бинарники из недоверенных путей; перед очисткой сборочных файлов проверяется COLLECT-00.toc.
- Добавлена воспроизводимая сборка основного EXE и неинтерактивный frozen smoke с контролем stdout, stderr и кода завершения.
- Windows CI запускает Ruff, unit-тесты и frozen-проверку.
- Установщик и portable-папка включают MIT-лицензию проекта, уведомление о сторонних компонентах и лицензию AutoHotkey.
- Тестовый путь пользователя заменён нейтральным примером.

## Версия 1.5.0 (2026-08-20)

*Релиз перестраивает интерфейс: вкладки возвращены в левую панель, справа — кнопки управления, инспектор окон и лог событий. Добавлено временное отключение правил и отдельных заголовков.*

### ✨ Новые возможности

- Вкладки «Правила», «Исключения» и «Система» возвращены в левую панель приложения; справа — кнопки «Старт/Стоп», управление правилами, инспектор окон (Spy) и лог событий.
- Вкладка «Правила» разделена на две колонки: список правил и форма настройки с перетаскиваемым разделителем.
- Чекбокс «Правило активно» временно отключает правило: оно помечается «(выкл)» в списке и пропускается при генерации скрипта.
- Индивидуальные чекбоксы заголовков: можно временно отключать отдельные заголовки правила.
- Заголовки правила теперь добавляются и удаляются кнопками «Добавить» и «Удалить выбранные».

### 🛠 Улучшения

- Кнопка «Сохранить изменения в правиле» перенесена в группу «Инспектор окон (Spy)».
- Разделители между списком правил и формой, левой и правой панелями, кнопками и логом перетаскиваются и сохраняют пропорции при смене масштаба интерфейса.
- Состояния сплиттеров больше не сохраняются в settings.json: стартовые размеры колонок задаются при первом показе окна, что исключает схлопывание интерфейса в одну колонку после обновления с прежних версий.

## Версия 1.4.0 (2026-08-09)

*Релиз добавляет переключатель «Пауза / Возобновить» в контекстное меню иконки системного трея.*

### ✨ Новые возможности

- В контекстное меню иконки в системном трее добавлен переключатель «Пауза / Возобновить».
- При включенной паузе приложение полностью прекращает регулировку размеров и позиций окон.
- Пауза действует на уже запущенный AutoHotkey-скрипт: он перезапускается с флагом Paused и не изменяет окна до снятия паузы.

### 🛠 Улучшения

- Добавлены unit-тесты генерации AHK-скрипта с флагом паузы.

## Версия 1.3.1 (2026-05-15)

*Релиз исправляет fallback-ярлык автозагрузки для систем с перенесенной папкой Startup.*

### 🐛 Исправления ошибок

- Fallback-ярлык автозагрузки теперь создается только в системно определенной папке Startup.
- Если `SHGetKnownFolderPath(FOLDERID_Startup)` недоступен, приложение берет Startup из настроек Windows в реестре.
- Жесткий путь `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup` больше не используется для создания нового ярлыка.

### 🛠 Улучшения

- Старый дефолтный Startup-путь оставлен только для удаления устаревших ярлыков, созданных предыдущими версиями.
- Добавлены regression-тесты для выбора пути Startup при перенесенной пользовательской папке автозагрузки.

## Версия 1.3.0 (2026-04-27)

*Релиз добавляет масштабирование интерфейса и исправляет автозапуск через планировщик Windows.*

### ✨ Новые возможности

- Добавлено адаптивное масштабирование интерфейса от размера экрана и DPI.
- Добавлена ручная поправка масштаба в разделе «Система» с сохранением в `settings.json`.
- Добавлены отдельные модули расчета и применения масштаба интерфейса.

### 🐛 Исправления ошибок

- Автозапуск теперь создается через задачу планировщика Windows с интерактивным запуском и повышенными правами.
- Устаревшие ярлыки автозагрузки удаляются при включении нового автозапуска.

### 🛠 Улучшения

- QSS, layout-отступы, размеры виджетов и иконок пересчитываются при смене масштаба.
- Добавлены unit-тесты для расчетов масштаба интерфейса.
- Post-build и installer больше не запускают приложение автоматически, чтобы не блокировать файлы сборки.
- Обновлена документация по автозапуску, масштабированию и релизному процессу.

## Версия 1.2.0 (2026-04-23)

*Релиз добавляет переносимость правил, исправляет запуск с правами администратора и приводит исходники к проектному окружению.*

### ✨ Новые возможности

- Добавлены импорт и экспорт правил и исключений в JSON-файл.
- Добавлен проектный `requirements.txt` для воспроизводимого запуска из исходников.
- Добавлена workspace-настройка VS Code для проектной `.venv` и Pylance.

### 🐛 Исправления ошибок

- Собранный `Resize_File_Dialogs.exe` теперь запрашивает права администратора через manifest PyInstaller.
- Запуск из исходников автоматически переходит на проектную `.venv`, если она существует.
- GUI-запуск `.pyw` теперь использует `pythonw.exe`, чтобы не оставлять пустое консольное окно.
- Добавлена runtime-проверка прав администратора с попыткой перезапуска через `runas`.

### 🛠 Улучшения

- `Build_Tools/post_build.py` копирует `VERSION` в финальную папку приложения.
- Обновлена документация по исходникам, сборке, installer/copy-скриптам и правилам релиза.
- Убраны lint-проблемы в измененных Python-файлах.
